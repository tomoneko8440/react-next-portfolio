# tomoneko's garage（react-next-portfolio）

ゲーム・車・音楽が好きな tomoneko のポートフォリオサイトです。作品とブログを microCMS で管理し、Next.js で表示しています。

## サイトURL

- 公開URL: **（Vercel で公開後にここへ記入）** 例: `https://react-next-portfolio-xxxx.vercel.app`
- リポジトリ: https://github.com/tomoneko8440/react-next-portfolio

## 概要

これまでに作ったもの（作品）と、制作の記録や学んだこと（ブログ）をまとめたサイトです。
内容は microCMS で管理しているので、コードを変えずに作品や記事を追加・更新できます。

## ページ構成

| ページ | パス | 内容 |
| --- | --- | --- |
| TOP | `/` | キャッチコピーと、最新の作品・ブログを 3 件ずつ |
| プロフィール | `/profile` | 自己紹介、できること、好きなこと |
| 作品一覧 | `/works` | microCMS `works` API の作品をカードで一覧表示 |
| 作品詳細 | `/works/[id]` | 作品のサムネイル・説明・本文・作品へのリンク |
| ブログ一覧 | `/blog` | microCMS `blogs` API の記事をカードで一覧表示 |
| ブログ詳細 | `/blog/[id]` | 記事のサムネイル・公開日/更新日・本文 |
| 404 | 存在しない URL | 存在しない作品・記事も 404 ステータスで「ページが見つかりません」を表示 |

全ページ共通でヘッダー（ナビゲーション）とフッターがあります。スマートフォンではヘッダーのボタンでメニューを開閉します。

## 使用技術

- Next.js 16（App Router）/ React 19 / TypeScript
- microCMS（`microcms-js-sdk`）
- CSS Modules（ライブラリを使わず自分で設計）
- `next/image` による画像最適化
- Vercel（ホスティング）

## デザイン方針

テーマは **「ガレージ」** です。ライト（昼のガレージ）とダーク（夜のガレージ）を、ヘッダーのボタンで切り替えられます。

- **配色**: ダークは濃紺の背景（`#0e1117`）に、レーシングカーのようなオレンジ（`#ff8a4c`）と、メーター照明のようなシアン（`#5fd8cc`）。ライトは温かみのある白（`#f7f4ee`）に濃紺の文字で、オレンジとシアンを濃くして読みやすくしました。どちらのテーマでも、文字色は背景とのコントラスト比 4.5:1 以上（WCAG AA）を計算で確認しています。
- **文字組み**: 本文は日本語が読みやすい行間 1.8〜2.0 と、詰めすぎない字間（`palt` で約物だけ詰める）。英字ラベルやナンバリング（`01 / WORKS`）は等幅フォントにして、計器やセッティングシートのような雰囲気にしました。
- **情報配置**: TOP は「何者か → 作品 → ブログ」の順に、見る人が知りたい順で並べました。一覧はカード型で、画面幅に合わせて 1〜3 列に自動で変わります。詳細ページは読みやすさを優先して本文幅を 800px までに絞っています。

## 選んだ理由

- 好きなゲームや車の世界観をサイトの見た目に取り入れることで、プロフィールを読まなくても「どんな人か」が伝わるようにしたかったからです。
- 暗い背景は作品のサムネイルが映えるので、作品を見せるポートフォリオに合うと考えました。
- CSS フレームワークを使わず CSS Modules で書いたのは、配色や余白を変数（CSS カスタムプロパティ）で管理する練習をしたかったからです。

## 力を入れた点

- **サムネイル未設定でも崩れない**: 画像の枠を 16:9 に固定し、画像がないときはストライプ柄の「No Image」を表示します。
- **存在しない作品・記事の扱い**: microCMS が 404 を返したら Next.js の `notFound()` につなぎ、本当に 404 ステータスを返すようにしました（読み込み中表示の位置を工夫して、ステータスが 200 にならないようにしています）。
- **表示速度**: ISR（60 秒ごとに再生成）で静的ページとして配信し、一覧では本文を取得しないよう `fields` を絞っています。画像は `next/image` で端末に合ったサイズ・形式に変換しています。
- **アクセシビリティ**: 「本文へスキップ」リンク、キーボード操作時のはっきりしたフォーカス表示、現在のページを示す `aria-current`、メニューの `aria-expanded` と Esc キーで閉じる動作、動きを減らす設定（`prefers-reduced-motion`）への対応。
- **ライト / ダークの切り替え**: 最初は OS の設定に合わせて表示し、ボタンで選んだテーマは保存して次回も使います。`<head>` の小さなスクリプトで描画前にテーマを反映するので、読み込み時に色がちらつきません。色はすべて `globals.css` 先頭の変数にまとめ、役割をコメントで書いているので、後から配色を変えやすくしています。
- **長く・誰でも見やすく**: リンクには下線を付けて色だけに頼らない、ボタンやリンクは押しやすい高さ 44px 以上、文字サイズは rem 指定でブラウザの文字サイズ設定に追従、印刷時は白い紙に黒い文字でメニューを出さない、などを意識しました。
- **ページごとのタイトルと説明**: 全ページに `title` と `description` を設定し、作品・記事の詳細では microCMS の内容から自動で作っています。`sitemap.xml` と `robots.txt` も自動生成します。

## microCMS の設定

サービスにリスト形式の API を 2 つ作ります。

### `works`（作品）

| フィールドID | 表示名 | 種類 | 必須 |
| --- | --- | --- | --- |
| `title` | タイトル | テキストフィールド | ○ |
| `description` | 説明（一覧・meta description に使用） | テキストエリア | |
| `thumbnail` | サムネイル | 画像 | |
| `thumbnailAlt` | サムネイルの代替テキスト | テキストフィールド | |
| `content` | 本文 | リッチエディタ | |
| `url` | 作品のURL | テキストフィールド | |

### `blogs`（ブログ）

| フィールドID | 表示名 | 種類 | 必須 |
| --- | --- | --- | --- |
| `title` | タイトル | テキストフィールド | ○ |
| `description` | 説明（一覧・meta description に使用） | テキストエリア | |
| `thumbnail` | サムネイル | 画像 | |
| `thumbnailAlt` | サムネイルの代替テキスト | テキストフィールド | |
| `content` | 本文 | リッチエディタ | |

`thumbnailAlt` が空のときは、タイトルを代替テキストとして使います。

## ローカルで動かす

```bash
npm install
cp .env.example .env.local   # 値を自分の microCMS のものに書き換える
npm run dev                  # http://localhost:3000
```

| 環境変数 | 内容 |
| --- | --- |
| `MICROCMS_SERVICE_DOMAIN` | microCMS のサービスドメイン（`xxxx.microcms.io` の `xxxx`） |
| `MICROCMS_API_KEY` | microCMS の API キー（GET 権限のみで OK） |
| `NEXT_PUBLIC_SITE_URL` | 公開URL（OGP・sitemap 用。末尾の `/` なし） |

`.env.local` は `.gitignore` に入っているので GitHub には含まれません。API キーはコードに直接書かず、Vercel では「Settings → Environment Variables」に登録します。
